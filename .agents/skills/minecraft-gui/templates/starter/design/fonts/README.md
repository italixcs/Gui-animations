# Inter font asset

`Inter-Regular.ttf` is the unmodified static regular font from the official
[Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), archive member
`extras/ttf/Inter-Regular.ttf`. The release archive's font name table reports
`Version 4.001;git-9221beed3`; that internal version is preserved, not rewritten.

Copyright (c) 2016 The Inter Project Authors. The font is distributed under the
SIL Open Font License 1.1. The release's `LICENSE.txt` is retained verbatim as
[OFL.txt](OFL.txt). Keep it with any redistributed font copy.
