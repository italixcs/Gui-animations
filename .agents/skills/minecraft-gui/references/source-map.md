# Packaged source map

This package contains the exact versioned starter sources and build pins shipped with this toolkit.

- [Standalone starter](../templates/starter/README.md): build and run the three-module demo.
- [Core module](../templates/starter/reference/core/build.gradle): optional elapsed-time motion helpers.
- [ModernUI adapter](../templates/starter/adapters/fabric-modernui/build.gradle): shared visual components and resources.
- [Showcase module](../templates/starter/examples/showcase-mod/build.gradle): client entry point and working settings screen.
- [Version pins](../templates/starter/gradle.properties): authoritative Minecraft, loader, renderer, and build-tool versions.
- [Design tokens](../templates/starter/design/tokens.json) and [component specifications](../templates/starter/design/component-specs/README.md).

- [Third-party notices](../templates/starter/THIRD_PARTY_NOTICES.md): font, wrapper, and dependency attribution.

Use sources matching the consuming project's build. A published source snapshot is not evidence that another Minecraft version works.
